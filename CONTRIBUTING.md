# Contributing

## Development

Use Flutter 3.27.0 or a compatible stable release. Run `flutter pub get`, `flutter gen-l10n`, `flutter analyze`, and `flutter test` before opening a change.

## Changes

Keep platform channel names and Android package identifiers consistent across Dart, Kotlin, manifests, and native resources. Add tests for behavioral changes and avoid committing credentials, keystores, generated build output, or local configuration.

## Review

Describe the user-visible behavior, affected platforms, validation performed, and any known limitations in the pull request.

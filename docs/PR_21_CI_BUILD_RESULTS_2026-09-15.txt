## Original workflow failure and fix

The Android, web, and iOS workflows initially failed before creating jobs because their step conditions used `secrets.*` directly in `if` expressions. GitHub rejected this context during workflow parsing with:

`Unrecognized named-value: 'secrets'`

The workflows were changed to calculate boolean job-level environment values from secrets and use `env.*` in conditions. The actual secret values remain used only where needed by the steps. After this fix, manual dispatch of the Android workflow was accepted and reached the runner.
